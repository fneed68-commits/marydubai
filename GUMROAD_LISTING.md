## 🔥 Key Features

### 1. Human-in-the-Loop (HITL)
Every agent stops and waits for explicit "yes" before executing.
No autonomous decisions. Ever.

Runs on Termux, Linux, macOS, Windows.
No internet required (optional Gemini API for better embeddings).
