# MaryDubai Multi-Agent System

## The Problem

Companies in security, finance, and legal sectors cannot use
AI agents because they lack:

- Human approval gates (HITL)
- Audit trails
- Safe execution controls
- Offline capability
- Specialized multi-agent coordination

## The Solution

MaryDubai is a production-ready Multi-Agent framework that
enforces strict human oversight at every decision point.

### Core Principles

1. NO EXECUTION WITHOUT EXPLICIT "yes" FROM HUMAN
2. Every agent stops and waits after each step
3. All decisions are logged with timestamps
4. Runs offline (no cloud dependency)
5. Works on Termux/Android/Linux
