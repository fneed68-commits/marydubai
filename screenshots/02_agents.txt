📋 الوكلاء المتاحون:

  [       rag]  وكيل RAG - بحث ذكي في قاعدة معرفة
  [     legal]  المستشار القانوني - تدقيق الامتثال
  [      loop]  كسر الحلقات اللانهائية
  [  temporal]  الحواف الزمنية - فحص الحدود الزمنية
  [ financial]  الاستثمار المالي - تحليل العوائد
  [      math]  الرياضيات والفيزياء
  [    wallet]  أمن المحافظ الإلكترونية

💡 أمثلة:
  python3 main.py --agent rag --query 'ما هي الثغرات؟'
  python3 main.py --agent legal --action 'تقرير CTF'
  python3 main.py --agent temporal --time 1.2
